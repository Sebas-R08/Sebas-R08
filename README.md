## Proyecto destacado

### Sistema Contable Jurídico

Plataforma web desarrollada para centralizar la gestión contable y operativa de un despacho jurídico.

El sistema permite administrar ingresos, egresos, préstamos, recibos, cuentas de clientes, cajas, cierres y reportes consolidados.

**Tecnologías utilizadas:**

- Node.js
- Express.js
- EJS
- MySQL
- Passport
- Bootstrap
- JavaScript

**Enfoque técnico:**

- Backend con Node.js y Express.
- Renderizado de vistas con EJS.
- Autenticación de usuarios con Passport.
- Gestión de información en MySQL.
- Organización de procesos administrativos y contables.
